# DEAD ZONE: ORIGIN — Unreal Engine 5.8

Toto je **samostatná pracovní větev** pro převod původního prototypu DEAD ZONE na realistické 3D postavy a prostředí. Výchozí projekt je v odděleném ZIP balíčku, který obsahuje C++, Config, Tools a vlastní jednoduché SourceArt.

**Pozor:** Tato větev zatím **neobsahuje kompletní projektové soubory ani hotové realistické modely**. Vznikla jako bezpečné místo pro přípravu jejich integrace bez zásahu do hlavní větve NIGHTFALL-THE-BELOW.

## Obsah a další krok
- `ASSET_SOURCES.md` — konkrétní zdroje realistických 3D postav a animací.
- `LICENSE_POLICY.md` — proč neukládat zakoupené / stažené Fab a Mixamo soubory veřejně.
- Původní zdrojový ZIP je nutné nahrát samostatně jako obsah tohoto adresáře nebo vytvořit nový dedikovaný repozitář.
- V Unreal Engine lze používat MetaHuman 5.6+ a připravené sloty pro SkeletalMesh (hráč, nakažení, Sabrina).

**Technický stav:** Kompilace a hratelnost původního C++ prototypu nebyla ověřena v Unreal Editoru. 10×10 km mapa je procedurální, nikoliv hotový produkční open-world svět.
