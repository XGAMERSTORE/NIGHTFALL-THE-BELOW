# LAST HAVEN: AFTER DARK

Independent Godot 4 Android game prototype inside NIGHTFALL-THE-BELOW.

This directory does not change any NIGHTFALL source files. It has its own Godot project and independent Android application ID: `com.xgamerstore.lasthaven`.

## Prototype
Build rooms, advance days, manage resources, save and load. This is a minimal playable systems prototype, not a finished graphical game. No explicit adult assets or scenes are included.

## APK
Run the separate GitHub Actions workflow `Last Haven Android APK`. Its artifact is named `last-haven-debug-apk`. Workflow requires compatible Godot 4.3 Android export templates and Android SDK.
